【二、学习目标】

学完本模块，你要能做到：

  1. 看懂基本的 C++ 代码，知道每一行在干嘛
  2. 自己动手写简单的程序，编译运行不出错
  3. 理解指针和内存，不害怕 * 和 &
  4. 能用面向对象的思想写类、写继承
  5. 知道 STL 是什么，会用 vector、string 这些基本容器

【四、学习顺序建议】

师傅给你划两条线，两条坎：

【第一道坎：指针（04 号文件）】
  很多人学 C++ 就栽在这了。
  指针这东西，光看没用，一定要动手画图。
  拿张纸，画内存格子，每个变量占几个格子，
  地址是多少，指针指向哪。画着画着就懂了。

  学指针的时候，一定要搞懂：
  - 栈内存和堆内存的区别
  - new 和 delete 要配对用
  - 什么是内存泄漏
  - 空指针和野指针的区别

【第二道坎：面向对象（07~08 号文件）】
  从面向过程转到面向对象，是思维方式的转变。
  别急，慢慢来。先理解"封装"，再理解"继承"，
  最后啃"多态"。多态是难点，但也是精华。

【学习方法】
  每个文件都要：
  1. 先读一遍代码，看懂注释
  2. 编译运行，看输出
  3. 改代码！改点东西试试效果
  4. 改出 bug 了，自己试着修

  光看不练，等于白看。


【五、核心知识点梳理】

咱把最重要的东西拎出来说说：

1. 【指针的本质】
   指针就是个变量，存的是地址。
   int* p;  // p 存的是一个 int 变量的地址
   *p;      // 去 p 存的地址那里取值
   &x;      // 取 x 的地址

2. 【引用 vs 指针】
   引用是别名，必须初始化，不能"改指向"。
   指针是变量，可以重新赋值，可以为 null。
   能用引用就用引用，实在需要指针再用指针。

3. 【类的三大特性】
   封装：把数据和操作数据的函数放一起
   继承：子类复用父类的代码
   多态：同一个接口，不同的实现

4. 【虚函数的作用】
   没有虚函数，指针是什么类型就调用谁的方法。
   有了虚函数，看指针实际指向什么对象，就调用谁的。
   这就是多态的本质。


【六、常见坑与注意事项】

1. 【数组越界】
   C++ 不检查数组下标越界！越界了不报错，
   直接乱读写内存，结果不可预测。
   用 vector 比原生数组安全多了。

2. 【野指针】
   指针 delete 之后，记得设为 nullptr。
   不然它还指着那块已经释放的内存，
   哪天不小心用了，就是个大 bug。

3. 【内存泄漏】
   new 了一定要 delete，malloc 了一定要 free。
   虽然现在有智能指针，但基础原理得懂。

4. 【= 和 == 搞混】
   if (a = 5) 这是赋值，永远为真！
   应该是 if (a == 5)。新手最容易犯。

5. 【头文件重复包含】
   记住要写 #pragma once 或者 #ifndef 保护。


【七、老师傅的经验之谈】

1. 【别怕报错】
   编译报错是好事！说明编译器在帮你找问题。
   真正可怕的是编译通过了，但运行结果不对。
   学会看报错信息，从第一条错误开始看。

2. 【指针一定要搞懂】
   徒弟，听师傅一句劝：指针和内存这块，
   一定要啃下来。不然后面学什么都是糊的。
   智能指针、STL 容器、虚函数表……
   底层全是指针。指针没搞懂，后面越学越糊涂。

3. 【代码风格很重要】
   缩进对齐、变量命名、注释……
   别觉得这是小事。代码写得乱，
   出了 bug 你自己都不想看。
   从一开始就养成好习惯。

4. 【多写多练】
   C++ 不是看书看会的，是写代码写会的。
   每个例子都自己敲一遍，改一改，试一试。
   敲错了、改不出来，那才是进步的时候。

5. 【遇到问题先自己想】
   遇到 bug 别急着问人。先自己琢磨半小时，
   把代码一行行读，把执行过程在脑子里走一遍。
   实在想不出来再查资料、问人。
   自己想出来的东西，记得最牢。
