学习建议

  • 先过一遍 exception_basics.cpp，对异常体系建立整体认知
  • 重点理解 RAII 思想——这是 C++ 异常安全的基石
  • 每个反例都要搞懂：为什么错、怎么改、后果是什么
  • 配合 tutorial.md 深入理解异常的设计哲学与争议
  • 做完小练习，尤其是 RAII 类和异常安全的练习
  • 在自己的项目里实践：用智能指针代替裸 new，用 lock_guard 管理锁

老师傅的话

很多人学 C++ 只学语法，觉得异常不就是 try/catch 嘛，有啥难的。 真到了项目里，内存泄漏了、死锁了、数据错乱了， 查半天发现就是某个异常路径没处理好。

异常安全这东西，光看不练没用。 你得真踩过几个坑，吃过几回亏， 才能真正明白"为什么要这么写"。 但别怕，踩坑的过程就是成长的过程。

记住 RAII 这四个字母。 在 C++ 里，手动管理资源是低级操作， 能用对象管的就别自己操心。 RAII 用好了，你的代码不仅异常安全， 还更简洁、更不容易出 bug。
