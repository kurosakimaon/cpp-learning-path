# ============================================================
#  CMake 示例 01 - 最基础的 CMakeLists.txt
#  老师傅注释版，每行都给你讲明白

# ---- 第 1 行：规定最低 CMake 版本 ----
# 徒弟你记好，CMakeLists.txt 的第一行几乎都是这个。
# 意思是："要构建这个项目，你电脑上的 CMake 版本至少得是 3.10"。
# 为什么要写这个？因为不同版本的 CMake 支持的命令不一样，
# 低版本的 CMake 遇到高版本的命令会报错。
# 就像你用老版本的微信，发不出去新出的表情包一个道理。
cmake_minimum_required(VERSION 3.10)

# ---- 第 2 行：给项目起个名字 ----
# project() 命令用来定义项目名称。
# 这个名字很重要，后面很多地方会用到（比如 ${PROJECT_NAME} 变量）。
# 这里我们把项目叫做 "HelloCMake"。
#
# 小知识：project() 还可以顺便指定项目版本、使用的语言等，
# 比如 project(HelloCMake VERSION 1.0 LANGUAGES CXX)
# 不过咱先从最简单的开始，一口吃不成胖子。
project(HelloCMake)

# ---- 第 3 行：告诉 CMake 要生成一个可执行文件 ----
# add_executable 是 CMake 最核心的命令之一。
# 格式是：add_executable(可执行文件名  源文件1  源文件2 ...)
#
# 这里的意思是：
#   用 main.cpp 这个源文件，编译生成一个叫 hello 的可执行程序。
#
# 注意：第一个参数 hello 是生成的可执行文件的名字，
#       Windows 下会自动变成 hello.exe，Linux 下就是 hello。
add_executable(hello main.cpp)
