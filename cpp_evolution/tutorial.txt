  C++ 版本演进（11 → 14 → 17）
  知其然，更要知其所以然

【一、模块简介】

徒弟啊，学 C++ 有个常见的误区：
上来就背各种特性怎么用，却不知道这些特性
是怎么来的、为什么要加。

师傅告诉你，理解"为什么会有这些特性"，
比"特性怎么用"更重要。因为只有理解了背后的
设计思想，你才能真正用好这些特性，
而不是死记硬背。

这个模块就带你梳理一下 C++11 到 C++17 的演进脉络，
看看 C++ 是怎么一步步变成今天这个样子的。


【二、学习目标】

学完本模块，你要能做到：

  1. 说清楚 C++11、C++14、C++17 各自的核心特性
  2. 理解每个特性是为了解决什么问题而引入的
  3. 对 C++ 的发展方向有个整体认识
  4. 知道不同版本之间的差异，写代码能注意兼容


【三、文件列表与学习重点】

咱一共 3 个文件，不多，但信息量很大：

  cpp11_core_features.cpp     ← C++11 核心特性（革命性！）
    重点：右值引用与移动语义、lambda、智能指针、
          auto/decltype、范围 for、nullptr、override/final

  cpp14_features.cpp          ← C++14 特性（小步完善）
    重点：泛型 lambda、变量模板、make_unique、
          返回类型推导、二进制字面量

  evolution_comparison.cpp    ← 版本演进对比（总览）
    重点：各版本特性对照表、演进脉络、设计思想变化


【四、学习顺序建议】

师傅建议你这么学：

【先看总览（evolution_comparison.cpp）】
  先把这个文件过一遍，建立整体概念。
  C++11 有什么、C++14 加了什么、C++17 又加了什么，
  心里有个大概的地图。

  别上来就扎进细节里，先看全貌。

【再深入 C++11（cpp11_core_features.cpp）】
  C++11 是革命性的版本，重要性怎么强调都不为过。
  可以说，C++11 之前是"古典 C++"，
  C++11 之后是"现代 C++"。

  C++11 的核心特性，每一个都要理解：
  - 右值引用和移动语义 → 性能革命
  - lambda 表达式 → 函数式编程入门
  - 智能指针 → 内存安全的基石
  - auto/decltype → 类型推导的开始
  - 范围 for → 语法糖，但很好用

【最后看 C++14（cpp14_features.cpp）】
  C++14 是个"小版本"，特性不多，
  主要是对 C++11 的完善和补充。
  快速过一遍就行，知道有这些东西。

  然后你可以对照 cpp17 模块的内容，
  看看 C++17 又加了什么。


【五、核心知识点梳理】

咱把三个版本的定位和核心说清楚：

1. 【C++11：革命性的版本】
   C++11 之前，C++ 已经停滞了好多年（C++98 之后几乎没大更新）。
   C++11 的推出，相当于给 C++ 换了个心脏。

   核心变化：
   - 内存管理：智能指针（shared_ptr/unique_ptr），告别裸指针
   - 性能：右值引用和移动语义，减少不必要的拷贝
   - 语法：auto、lambda、范围 for，代码更简洁
   - 类型系统：nullptr、强类型枚举（enum class）
   - 模板：变参模板、decltype
   - 并发：线程库、原子操作、内存模型

   一句话：C++11 让 C++ 重新活了过来。

2. 【C++14：小步完善的版本】
   C++14 没什么革命性的东西，
   主要是把 C++11 没做完的做完，
   顺便加点小特性。

   代表特性：
   - 泛型 lambda：lambda 参数可以用 auto
   - 变量模板：模板也可以用于变量
   - make_unique：补上 unique_ptr 的工厂函数
   - 返回类型推导：函数返回值也可以用 auto
   - 二进制字面量：0b1010 这样写

   一句话：C++14 是 C++11 的"补全补丁"。

3. 【C++17：语法糖大礼包】
   C++17 的特性很多，但大部分是"锦上添花"的语法糖。
   虽然不是革命性的，但确实让代码更好写了。

   代表特性：
   - 结构化绑定：auto [a, b] = pair;
   - if constexpr：编译期条件判断
   - 折叠表达式：可变参数模板展开更简单
   - optional/variant/any：三个实用类型
   - string_view：字符串视图，避免拷贝
   - filesystem：标准文件系统库
   - 并行算法：STL 算法的并行版本

   一句话：C++17 让 C++ 写起来更舒服了。

4. 【演进的整体趋势】
   从 C++11 到 C++17，你能看到几个明显的趋势：
   - 越来越"好用"：语法糖越来越多，代码越来越简洁
   - 越来越"安全"：智能指针、类型系统增强，减少错误
   - 越来越"函数式"：lambda、算法库，函数式风格越来越流行
   - 越来越"抽象"：模板元编程、constexpr，编译期计算越来越强


【六、常见坑与注意事项】

1. 【版本兼容问题】
   你用了 C++17 的特性，代码就不能在只支持 C++11 的
   编译器上编译了。项目用什么标准，要看清楚。
   一般编译选项里会指定：-std=c++11 / -std=c++14 / -std=c++17

2. 【不要迷信新版本】
   新版本特性虽好，但也要看项目情况。
   老项目、需要兼容老编译器的，就别追新。
   新项目、能控制编译器版本的，可以大胆用。

3. 【特性不是越多越好】
   有人觉得 C++ 特性越来越多，越来越复杂。
   其实很多特性你可能一辈子都用不上。
   掌握常用的就够了，冷门的知道有这么回事就行。

4. 【向前兼容】
   C++ 标准委员会非常重视向后兼容。
   老代码在新编译器上基本都能编过。
   所以不用担心学了新版本，旧代码就看不懂了。


【七、老师傅的经验之谈】

1. 【理解"为什么"比记住"是什么"重要】
   徒弟，师傅再强调一遍：
   学语言特性，别光记语法，要想它是为了解决什么问题。

   比如：
   - 为什么要有移动语义？因为深拷贝太浪费性能。
   - 为什么要有智能指针？因为手动管内存太容易出错。
   - 为什么要有 lambda？因为写个函数对象太麻烦。
   - 为什么要有 optional？因为返回 null 指针不安全。

   理解了"为什么"，你就知道什么时候该用，
   而不是为了用特性而用特性。

2. 【C++11 是基础中的基础】
   不管你用的是 C++14 还是 C++17，
   C++11 的特性都是天天要用的。
   auto、智能指针、移动语义、lambda……
   这些是现代 C++ 的基本功。
   C++11 没学好，后面都是空中楼阁。

3. 【版本演进是循序渐进的】
   你看 C++ 的发展，不是一蹴而就的。
   一个特性，可能从提案到进入标准要花好多年。
   先在 C++11 出个雏形，C++14 完善一下，
   C++17 再加个语法糖。

   学的时候也一样，不用急着一步到位。
   先学会用，再深入原理，慢慢积累。

4. 【关注 C++ 的未来】
   C++20 出了概念（concepts）、协程（coroutines）、
   模块（modules）、范围库（ranges）……
   C++23 又加了一堆东西。

   不用现在就学，但可以关注一下发展方向。
   知道 C++ 往哪走，你才能跟得上时代。

5. 【语言是工具，思想是根本】
   说到底，语言特性只是工具。
   RAII 思想、封装抽象、性能意识……
   这些才是根本。
   语言会变，思想不会变。
   把思想吃透了，什么语言都能快速上手。


【十、C++20/23 速览】

前面讲的都是 C++11 到 C++17，那 C++20 和 C++23 呢？

C++20 可以说是继 C++11 之后又一个"大版本"，
加入了很多重量级特性。
C++23 则是在 C++20 基础上的完善和补充。

这里给你做个快速概览，详细内容请看 cpp20_overview.cpp。

1. 【C++20 四大特性】

   （1）Concepts（概念）
       给模板参数加上约束，让模板接口更清晰，
       错误信息更友好。比老式的 SFINAE 好用太多。

   （2）Ranges（范围库）
       更优雅的算法库，支持管道式写法。
       数据像流水一样经过一道道处理，代码可读性大大提升。

   （3）Coroutines（协程）
       可以暂停和恢复的函数，异步编程新范式。
       让异步代码写起来像同步代码一样直观。

   （4）Modules（模块）
       替代 #include 的新模块化机制。
       编译更快、更干净，真正的封装性。

2. 【C++23 重要特性】

   （1）std::expected
       类似 Rust 的 Result 类型，错误处理新方式。
       函数要么返回正常值，要么返回错误，类型安全且清晰。

   （2）std::print / std::println
       终于有了既简洁又类型安全的格式化输出！
       结合了 printf 的简洁和 cout 的类型安全。

   （3）std::mdspan
       多维数组视图，给一维数据提供多维访问方式，
       零开销、性能好，适合科学计算等场景。

   （4）其他小改进
       - if consteval（编译期判断）
       - std::string::contains()（终于有了！）
       - std::flat_map / std::flat_set（基于数组的有序容器）
       - 更完善的 constexpr 支持
       - std::ranges::to（range 转容器）

3. 【学习建议】

   - C++20/23 的特性很多，但不用急着全学会。
   - 先把 C++11/14/17 的基础打牢，再往上走。
   - 可以从最实用的特性开始尝试，比如 ranges、format/print。
   - Concepts、Modules 这些改变编程范式的特性，
     等项目环境支持了再深入学习也不迟。

   详细内容和示例代码，请看 cpp20_overview.cpp。
