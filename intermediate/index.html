🦋 蜕变期 · STL 与内存

从 C 式编程迈向 C++ 式编程 · RAII 思想 + STL 三板斧

📖 模块简介

度过了筑基期，你已经掌握了 C++ 的基本语法。但如果你还在用 C 的方式写 C++ 代码（手动 new/delete、自己写链表）， 那你还没真正体会到 C++ 的威力。本模块将带你完成一次蜕变——理解 C++ 的内存模型和 RAII 思想， 熟练使用 STL 容器和算法，学会用智能指针管理内存。

这是一个重要的转折点。学完本模块，你的代码质量会有质的飞跃：更安全、更简洁、更符合 C++ 的"道"。

📚 学习建议

  • 先搞懂 RAII：RAII 是 C++ 一切优雅特性的基石。智能指针、容器、锁守卫，全都是 RAII 的应用。把这一章吃透，后面学什么都一通百通。
  • STL 容器要"知其然更知其所以然"：不光要会用 vector、map，还要理解它们的底层实现（动态数组、红黑树、哈希表），这样才能根据场景选对容器。
  • 多用算法，少手写循环：STL 算法已经帮你实现了最常见的操作，而且经过高度优化。学会用 std::sort、std::find、std::for_each 等，代码会更简洁更不容易错。
  • 彻底告别裸 new/delete：学完智能指针后，你的代码里应该尽量不再出现裸 new/delete。用 unique_ptr 和 shared_ptr 管理内存，从源头上杜绝内存泄漏。
  • 编程规范越早养成越好：代码是写给人看的，顺便给机器执行。好的编码习惯让你和你的同事都受益。从现在开始就按规范写代码。

👴 老师傅的话

徒弟，恭喜你来到蜕变期。这一关过了，你就从"会写 C++ 代码"变成了"会用 C++ 写代码"。这中间的区别，可大了去了。

很多人学 C++ 学了好几年，还停留在 C with class 的水平。手动管理内存、自己造轮子、到处是裸指针。 不是说这样不行，而是这样写出来的代码容易出 bug，而且维护成本高。

师傅跟你说几句掏心窝子的话：

  • RAII 是 C++ 的灵魂。 这句话你可能听很多人说过，但只有真正理解了它，你才会知道它有多厉害。资源获取即初始化，一句话道尽了 C++ 的哲学。构造函数获取资源，析构函数释放资源，对象出作用域自动清理。就这么简单的一个思想，解决了多少内存泄漏、资源泄漏的问题。
  • STL 是前人给你铺好的路。 别自己写链表、自己写排序、自己写哈希表了。STL 里的东西，都是全世界最聪明的人写的，经过了几十年的检验。你写的大概率没它好，也没它快。
  • 智能指针不是银弹，但没有它万万不能。 该用 unique_ptr 就别用 shared_ptr，后者有开销。weak_ptr 是解决循环引用的钥匙，务必搞懂。
  • 好代码是改出来的。 写完一版代码，回头看看能不能用 STL 算法替换手写循环，能不能用智能指针替换裸指针，能不能用 const 修饰更多地方。这个打磨的过程，就是你进步的过程。

加油吧，蜕变期过了，你就可以去学现代 C++ 的那些酷炫特性了。但在那之前，先把基本功练扎实。
